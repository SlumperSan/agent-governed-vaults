The target chain

Robinhood Chain is the target, and nothing is deployed there.

The stated target chain is Robinhood Chain mainnet, chain id 4663, and its parameters are the reference configuration contracts/config/robinhood-mainnet.json. Nothing from this repository is deployed there, or on any other mainnet. That file is a configuration read back from the chain by read-only JSON-RPC on 2026-09-04, not a deployment record, and it says so in its own status field.

Two things about that chain differ from the configuration this site used to quote, and both are stated here rather than left to a diff. The settlement token is USDG, the Global Dollar, not Circle USDC. And Chainlink publishes no L2 Sequencer Uptime Feed for chain 4663, so the sequencer gate never runs at price time there and the per-asset heartbeat and sane-price band carry that risk alone — an owner-approved weakening dated 2026-09-04, recorded in docs/DEPLOYMENT.md.

Standing facts

Four sentences the guard pins.

Verification

How to verify these claims.

Every claim on this page is a file you can open. The repository is public, including the launch-readiness board and every review round.

  • The address book: every address above, plus the note recording how each was read back on-chain and what the record deliberately does not prove.
  • The lifecycle transaction table: the ten phases, block by block, with the receipts.
  • The reference configuration: every parameter this site quotes for the target chain, each annotated with how it was read from chain 4663 and what was not checked.
  • The go/no-go board: the verdict, all nine gates, and the residual-risk register behind them.
  • The wording guard for this site: it pins the exact sentences above, bans the claim shapes these pages may not make, and reads the contract configuration to catch a page that has gone stale against it.
  • The repository-wide claims guard and the config-versus-docs guard: the same discipline applied to the documentation, so a claim cannot escape by moving out of the site.

All three suites run in CI on every change. Green is necessary and not sufficient, which is why the files themselves are linked rather than a badge: read the contracts rather than this description of them.
