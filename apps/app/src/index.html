Nothing is cached and nothing is served from a database.

Net asset value and capacity are in USDG, the settlement token on this chain, at six decimals. Share price is net asset value divided by shares outstanding. There is no return column: this protocol publishes no performance history, and a figure implying one would not be readable from the chain.

How to check this page

Both the count and the addresses come from the factory, 0xc44B853F037b4fF33B831C9a2B341686dEC88Fd1: vaultCount() for the number, then allVaults(i) for each address. The factory's address is the only one this page carries, so the vault list cannot fall behind the chain. Call the same two functions on the explorer and you should get the same addresses in the same order.
